# sdk

Runtime-agnostic TypeScript SDK for the Cloudflare Test control plane API

A shared package of the cloudflaretest workspace, consumed by the components
below at build time.

## Depended on by

- **cli** — First-class TypeScript CLI for the Cloudflare Test control plane API
- **web-console-next** — Next.js 15 + opennextjs/cloudflare delivery of the Cloudflare Test web console (per-environment, Workers + Static Assets)
